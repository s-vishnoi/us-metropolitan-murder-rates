# Poverty and ethnic diversity predict US metropolitan murder rates over 60 years

Code and notebooks for the associated manuscript.

## Setup

```bash
conda env create -f environment.yml
conda activate nature-cities-murders
jupyter lab
```

See [`notebooks/README.md`](notebooks/README.md) for the notebook order. Data sources and expected file locations are documented in [`data/README.md`](data/README.md). Processed data are available to editors and reviewers upon request.
